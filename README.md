# 🎓 Student Management System

A console-based **Student Management System** developed in **Python** using **Object-Oriented Programming (OOP)** principles and a modular project structure.

This application allows users to manage student records efficiently through a menu-driven interface while demonstrating concepts such as classes, file handling, validation, and modular programming.

---

## ✨ Features

- ➕ Add Student
- ❌ Remove Student
- 🔍 Search Student by ID
- ✏️ Update Student Information
- 📋 Display All Students
- 🔤 Sort Students by Name
- 📊 Sort Students by Grade
- 📈 View Student Statistics
  - Total Students
  - Average Grade
  - Highest Grade
  - Lowest Grade
- 💾 Save Student Records
- 📂 Load Student Records

---

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Aun-Ali-70/Student-Management-System-Python.git
```

2. Navigate to the project folder:

```bash
cd Student-Management-System-Python
```

3. Run the application:

```bash
python main.py
```
